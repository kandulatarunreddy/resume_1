02 / EVENT-DRIVEN COMMERCEPERSONAL PROJECT

DropflowFlash Sale Inventory Platform

Limited inventory. Concurrent buyers. Delayed events. A commerce systems lab designed around what happens when the happy path breaks.

Java / Spring BootRabbitMQPostgreSQLReactPython / ML
The problem
Flash-sale traffic creates stock contention, duplicate payments, expired reservations, and partially completed orders.
The engineering
Conditional inventory updates, a transactional outbox, inbox deduplication, publisher confirmations, retry queues, and dead-letter routing. Expiry and compensation handle late payments and failed fulfillment.
The ML boundary
A local ridge regression is evaluated against a seasonal baseline using synthetic demand history. Forecasts suggest replenishment; they never silently change inventory.
